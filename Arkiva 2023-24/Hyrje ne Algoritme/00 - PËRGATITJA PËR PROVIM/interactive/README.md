# Algoritmet Lab

Mini-platformë interaktive për materialin **Hyrje në Algoritme**.

## Si hapet

1. Shkarko folderin `interactive` ose tërë repository-n.
2. Hape `index.html` me Chrome, Firefox, Edge ose Safari.
3. Progresi dhe XP ruhen automatikisht në browser me `localStorage`.

Nuk kërkon instalim, server, llogari ose internet.

## Çka përmban

- 12 tema dhe 102 detyra me kontroll automatik;
- hints dhe zgjidhje për çdo detyrë;
- pseudokod checker për flowcharts;
- analizë live të kompleksitetit;
- postfix evaluator dhe circular queue;
- visualizers për Selection, Insertion, Shellsort, Mergesort dhe Quicksort;
- heap, symbol table, BST dhe LLRB playgrounds;
- simulator për chaining/probing dhe kalkulator Horner;
- FileIndex builder dhe sparse dot product;
- detyrë random, XP dhe progres të ruajtur.
- provim simulues me 20 pyetje, 100 pikë, timer 75 minuta dhe prag 80 pikë.

## Zhvillim lokal opsional

Mund të hapet direkt si file. Nëse dëshiron ta shërbesh lokalisht:

```bash
python3 -m http.server 8000 --directory interactive
```

Pastaj hape `http://localhost:8000`.
