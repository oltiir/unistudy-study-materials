| **Qëllimet dhe Objektivat** | Studenti të përgatitet me strukturat matematike diskrete si pjesë e matematikës së fundme, siç janë struktura algjebrike e kodeve, probabiliteti,statistika, rekurencat dhe PPL. Ky aparat matematik gjen zbatim si në disiplinat matematike ashtu edhe në shkencat e tjera natyrore, teknike, kompjuterike, ekonomike etj. | | | |
| **Parakushtet** | Të ketë dëgjuar Matematikë 1,2 dhe Strukturat Diskrete 1 | | | |
| **Rezultatet e pritshme** | Programi i lëndës korrespondon me teorinë e shumë lëndëve matematike, në radhë të parë me Teorinë e probabilitetit dhe të statistikës, Teorinë e kodimit, Strukturat algjebrike, Qarqet digjitale, Softveret aplikative, Modelimet etj.  Me njohuritë e fituar nga teoria algjebrike e kodeve, probabilitet, statistika, rekurencat dhe PPL, studenti aftësohet për të zbatuar njohuritë e fituara në përpilimin e softvereve të ndryshme për nevojat e shkencave kompjuterike, informatikë, statistikë, etj. | | | |
| **Përmbajtja** | **Plani** | | |  |
| Java 1. Hyrje në teorinë e kodimit, parametrat. Kodete binare lineare.  Java 2. Hapësirat vektoriale, dhe kodet e përgjithshme lineare.  Java 3. Kodimi i kodeve lineare. Matricat për kontoll dhe dekodim linear. Kodet Hamming. Kodet ciklike.  Java 4. Ngjarjet e rastit. Bashkësia e ngjarjeve elementare. Veprimet me ngjarje. Përkufizimi i probabilitetit të ngjarjes dhe vetitë.  Java 5. Probabiliteti i kushtëzuar. Pavarësia e ngjarjeve të rastit.  Java 6. Ndryshoret diskrete të rastit. Karakteristikat numerike të ndryshores së rastit. Probabiliteti binomial.  Java 7. Kuptimi i popullacionit dhe mostres.Tabela e të dhënave. Paraqitjet grafike për një ndryshore.  Java 8. Vlerat mesatare. Parametrat e pozicionit dhe të dispersionit  Java 9. Elemente të statistikës vendimore. Kontrolli i hipotezës për mesataren e një shpërndarjeje normale,  Java 10. Funksioni gjenerues. Veprimet.  Java 11. Teorema binomiale e zgjeruar. Funksionet gjeneruese eksponenciale.  Java 12. Ekuacionet rekurente homogjene dhe johomogjene | | | |
